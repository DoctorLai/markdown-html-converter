# Privacy Notice

Last updated: 2026-07-17

Markdown conversion runs entirely in your browser. The application does not send Markdown input or generated HTML to a project-operated server.

The application stores the following data in browser local storage:

- `markdown-html-converter:dark-mode`: whether dark mode is enabled.
- `markdown-html-converter:markdown`: the Markdown source draft.
- `markdown-html-converter:html`: the generated HTML draft.

Use the application's **Clear** button to empty both saved drafts. Clear the site's browser data to remove all stored application data, including the theme preference.

The site is hosted by GitHub Pages. GitHub may process technical information such as IP addresses and request logs under the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). External links are governed by their respective privacy policies.

Do not enter confidential content on a device or browser profile you do not trust. This notice will be updated when the application's data handling changes.
