# Changelog

All notable changes to this project are documented here. This project uses date-based versions.

## [2026.7.17] - 2026-07-17

### Added

- GitHub Pages deployment with visible build date and commit metadata.
- Pull request coverage reporting and 80% minimum coverage thresholds.
- ESLint, aggregate quality checks, Dependabot, and repository community files.
- Dynamic JavaScript percentage badge generated from GitHub language data.
- Responsive editor layout and interaction tests.
- Sanitization of generated HTML before rendering the live preview.

### Changed

- Namespaced the dark-mode preference in local storage.
- Updated dark-mode link and footer colors for improved visibility.
- Removed unused browser crypto and obsolete Jest/Babel dependencies.
- Consolidated deployment on a checked, least-privilege GitHub Actions workflow.
