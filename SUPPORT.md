# Support

## Using the Application

For setup and usage guidance, start with the [README](README.md). Search [existing issues](https://github.com/DoctorLai/markdown-html-converter/issues) before opening a new one.

Use a GitHub issue for reproducible bugs and feature requests. Include the browser and operating system, clear reproduction steps, expected behavior, and screenshots when relevant.

## Security and Privacy

Do not report vulnerabilities publicly; follow the [Security Policy](SECURITY.md). For information about data handling, see the [Privacy Notice](PRIVACY.md).

Support is provided by maintainers and contributors on a best-effort basis. There is no guaranteed response time or service-level agreement.
